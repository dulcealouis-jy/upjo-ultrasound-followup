# Deployment

1. Create a public GitHub repository and upload `app.py`, `requirements.txt`, and `.streamlit/config.toml`.
2. Sign in to Streamlit Community Cloud at https://share.streamlit.io/.
3. Select **Create app**, choose the repository, and set the main file to `app.py`.
4. Choose a short app subdomain, for example `upjo-ultrasound-followup`.
5. The intended public address is `https://upjo-ultrasound-followup.streamlit.app/` if that subdomain is available.

A public URL cannot be activated without access to the author's GitHub and Streamlit accounts.
