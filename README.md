# UPJO Ultrasound Follow-up Assessment

Public, browser-based post-pyeloplasty ultrasound follow-up assessment tool.

- Live tool: https://dulcealouis.github.io/upjo-ultrasound-followup/
- All calculations run locally in the browser.
- No entered clinical information is transmitted or stored.
- The original Streamlit implementation is retained in `app.py` for reproducibility.

This cohort-derived reference supports interpretation of structural remodelling after paediatric pyeloplasty. It does not diagnose recurrent pelvi-ureteric junction obstruction or determine reoperation.
